How to try this demo

  1. 1
    Pick a scenario, then ask a suggestion

    Or write your own — each scenario has its own focused set of tools. "What can this agent do?" on any scenario card shows the full list before you commit to one.

  2. 2
    Watch the trace, not a spinner

    Every tool call streams in as it happens — which tool, what arguments, what it returned — before the final answer.

  3. 3
    Try a multi-tool question

    The suggestions that chain several tools are the ones that actually show what an agent is, versus a chatbot with extra steps.

Safe by construction

🔒 Each scenario's tools are scoped by an allowlist — an agent running the Sales scenario cannot reach the Logistics or Service tools, or the separate read-only SQL tool, even though all of them are registered on the same MCP server.

⏳ Your questions and the agent's responses aren't stored beyond this session — nothing is written to a persistent log.
